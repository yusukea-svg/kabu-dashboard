# データ提供元と利用条件メモ

新しいデータ源を追加するときは、ここに利用条件を確認した日付とともに追記する。

| 提供元 | 用途 | 方針 |
|--------|------|------|
| JPX 東証上場銘柄一覧 | 銘柄マスタ | 実行時に取得しDBへ。リポジトリにファイルを置かない |
| JPX 決算発表予定日（kessan*.xlsx） | 毎週月曜の決算予定通知 | 実行時に取得し、本人の Discord に送るだけ。DB・リポジトリには保存しない。JPXサイトの規約は許諾のない二次利用・再配信を禁じているので、第三者に見える場所へは流さない（2026-10-23 確認） |
| yfinance（Yahoo Finance の非公式クライアント） | 日足・場中 | 個人利用・非公開・低頻度に限定（利用者が許容済み 2026-10-15）。価格をログ・Artifacts・Cache・リポジトリに出さない |
| J-Quants 無料プラン | バックテスト（フェーズ4） | 個人利用・再配布不可。結果（統計値）のみ保存 |
| EDINET API | 開示（フェーズ3） | 公式API・要APIキー |
| TDnet | 開示（フェーズ3） | 無料APIなし・スクレイピングしない。検索リンクの表示のみ |
| FRED | マクロ（フェーズ3） | 要APIキー。系列ごとの著作権表示に注意 |
| Yahoo!ニュース RSS（経済・国際） | 見出し（フェーズ3） | 見出し・リンク・日時のみ。本文は保存しない。出典名を表示しリンク先で読む。個人・非公開の利用（2026-10-15 確認） |
| NHK RSS（経済） | 見出し（フェーズ3） | 同上。NHK の RSS は個人利用の範囲で使う |
| Yahoo!ファイナンス・株探 | 適時開示 | 取得しない。銘柄ページから外部リンクするだけ |

## 非公開を保つための決まり

- ダッシュボードはログイン必須（Supabase Auth + RLS、許可メールのみ）。
- 公開リポジトリの Actions ログは誰でも見られる → 価格の値を出力しない（件数のみ）。
- `actions/upload-artifact` と `actions/cache` に取得データを入れない。
- `.gitignore` で CSV / Parquet / SQLite / Excel / `data/` を除外し、CI でも検査する。
