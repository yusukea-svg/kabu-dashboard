# kabu-dashboard

日本株の情報をまとめて見るための、**個人用**ダッシュボード（PWA）。

> 本ツールは個人の情報整理用であり、投資助言ではありません。自動売買・銘柄推奨は行いません。
> このリポジトリには株価等の取得データを含めません（各データ提供元の規約に従い、再配布しません）。

## 構成

```
batch/      Python：銘柄一覧・日足の取得、テクニカル指標、ユニバース判定（→ Supabase）
web/        Next.js（静的エクスポート）+ PWA：一覧・チャート。ログイン必須
config/     絞り込み条件・取得設定（YAML）
supabase/   DBスキーマ（RLSで自分のアカウントだけが読める）
docs/       設計・セットアップ・データ利用条件
```

- 設計：[docs/DESIGN.md](docs/DESIGN.md)
- セットアップと動作確認：[docs/setup.md](docs/setup.md)
- データ提供元と利用条件：[docs/terms.md](docs/terms.md)
